Built with [Lit](https://lit.dev/), they work in any page, framework or not,
and take their colours from CSS custom properties.

- **minimal-navbar** ([demo](https://firstprateek.github.io/minimal-navbar/),
  [source](https://github.com/firstprateek/minimal-navbar)): a responsive
  navigation bar that switches to a mobile layout below a breakpoint you set.
- **hamburger-btn** ([demo](https://firstprateek.github.io/hamburger-btn/),
  [source](https://github.com/firstprateek/hamburger-btn)): a menu button.
- **switch** ([demo](https://firstprateek.github.io/switch/),
  [source](https://github.com/firstprateek/switch)): a toggle switch, used as a
  theme switch.
- **poll-widget** ([demo](https://firstprateek.github.io/poll-widget/),
  [source](https://github.com/firstprateek/poll-widget)): an embeddable,
  customisable poll.
- **bar-chart** ([demo](https://firstprateek.github.io/bar-chart/),
  [source](https://github.com/firstprateek/bar-chart)): a bar chart drawn with
  D3 that can render real-time data.

They predate everything else on this site.
